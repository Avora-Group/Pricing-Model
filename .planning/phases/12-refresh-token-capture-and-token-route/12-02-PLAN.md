<objective>
Give a signed-in browser a tracker-scoped access token from its own origin. `POST /api/tracker/token` checks ACMI's own session, opens `tracker_rt` and redeems it with `redeemTrackerToken`. When Entra rotates the refresh token, it keeps the cookie fresh. It answers every failure in JSON through `tokenErrorResponse`, never a redirect. Then a human confirms the Entra consent and sets the local env, so the end-of-phase UAT can run.

Purpose: Phase 13's dialog wrapper calls this route before it opens the tracker dialog. Its contract (status codes, JSON bodies, `no-store`, never a redirect) is the one the package's browser getter expects.

Output: one new route, one HTTP smoke runner, static route checks added to `tests/rt-wiring.test.mjs`, one local commit, and a human checkpoint for D-11 and D-15. No push.

```ts
export interface RedeemTrackerTokenOptions {
  tenantId: string | undefined;      // missing or empty -> 'unconfigured', no network call
  clientId: string | undefined;      // missing or empty -> 'unconfigured', no network call
  clientSecret: string | undefined;  // missing or empty -> 'unconfigured', no network call; never logged or returned
  refreshToken: string | undefined | null;  // missing -> 'reauth'
  scope: string | undefined;         // api://<tracker-client-id>/access_as_user; the package appends offline_access
  fetch?: typeof fetch;
  now?: () => number;
}
export interface RedeemedTrackerToken { accessToken: string; expiresAt: number; refreshToken?: string }  // refreshToken present when Entra rotated
export declare function redeemTrackerToken(options: RedeemTrackerTokenOptions): Promise<RedeemedTrackerToken>;  // rejects with TrackerTokenError
export declare function tokenResponse(result: { accessToken: string; expiresAt: number }): Response;  // 200, body { accessToken, expiresAt } only, Cache-Control: no-store
export declare function tokenErrorResponse(error: unknown): Response;  // 401 reauth, 403 consent, 503 config/unconfigured, 502 unavailable; body { error }; no-store
// TrackerTokenError: .code is one of 'reauth' | 'consent' | 'config' | 'unconfigured' | 'unavailable'; .entraCodes is number[] (filtered by the package)
```
`tokenResponse` builds its body from `accessToken` and `expiresAt` only, so a rotated refresh token is never sent to the browser. Both helpers return a plain `Response` with mutable headers. `new NextResponse(res.body, res)` keeps the status, `Content-Type` and `Cache-Control: no-store`, and adds `out.cookies.set` and `out.cookies.delete` (verified 2026-10-01). A non-`TrackerTokenError` passed to `tokenErrorResponse` becomes `502 unavailable`.
